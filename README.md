# Medium Landing Page Redesign

This project is a redesign of the Medium landing page, created as my very first project during my journey as a Frontend Developer at **Betechified Afriica**.

##  Project Overview
The goal of this project was to replicate and slightly enhance the Medium landing page. This was a challenge to test my understanding of HTML structure and CSS styling early in my career.

### Key Features:
- Re-designed UI based on the Medium landing page.
- Custom "minor edits" to improve the visual flow.
- Fully hosted via GitHub Pages.

## My Journey
This project marks a significant milestone in my coding journey:
- **Timeline:** I had been coding for exactly **3 weeks** when I built this.
- **Milestone:** This is my **first-ever live page** deployed to the web.

While the code reflects my early stages of learning, it represents the foundation of my frontend development skills.

## Technologies Used
- HTML5
- CSS3 (Flexbox/Grid)
